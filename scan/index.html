Generador de Recursos Ley 21.719

Fragmentos de código listos para implementar en tu sitio web y cumplir con el artículo 3 letra f (Principio de Seguridad).

1. Cabeceras HTTP de Seguridad (.htaccess para Apache / Hostinger)

<IfModule mod_headers.c>
    Header always set Strict-Transport-Security "max-age=63072000; includeSubDomains; preload"
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set X-Content-Type-Options "nosniff"
    Header always set Referrer-Policy "strict-origin-when-cross-origin"
    Header always set Permissions-Policy "geolocation=(), microphone=(), camera=()"
</IfModule>

2. Checkbox de Consentimiento Libre e Informado (HTML5)

Guía de la Ley N° 21.719 de Protección de Datos Personales

Sustituye a la antigua Ley N° 19.628, introduciendo estándares equivalentes al Reglamento General de Protección de Datos (GDPR) de la Unión Europea en Chile.

⚖️ Principios Fundamentales

  • Licitud y Consentimiento: Tratamiento basado en consentimiento libre, explícito e informado.
  • Minimización: Solo se recopilan los datos estrictamente necesarios.
  • Seguridad e Inmutabilidad: Obligación de implementar medidas técnicas de protección.

🛡️ Derechos ARCOP+B

  • Acceso, Rectificación, Cancelación, Oposición, Portabilidad y Bloqueo.
  • Plazo máximo de respuesta ante el titular de los datos: 15 días hábiles.

🚨 Sanciones y Multas

  • Infracciones Leves: Hasta 5.000 UTM.
  • Infracciones Graves: Hasta 10.000 UTM.
  • Infracciones Gravísimas: Hasta 20.000 UTM o el 4% de los ingresos anuales.

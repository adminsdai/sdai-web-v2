# Modelo de Capacidades y Madurez SDAI PYME

**Estado:** BASELINE  
**Versión:** 1.0  
**Fecha:** 2026-09-23

## Regla conceptual

Un control del assessment no es una capacidad. El control observa una práctica; la capacidad representa aquello que la organización debe desarrollar y sostener.

Los dominios estratégicos de referencia SDAI son DATA, CYBER, PRIVACY y AI. Continuidad se mantiene como subfamilia de CYBER; no se crea un quinto dominio estratégico.

## Escala de madurez

- **M0 Inexistente:** no existe práctica identificable.
- **M1 Inicial:** práctica reactiva y dependiente de personas.
- **M2 Básica:** práctica habitual y parcialmente estructurada.
- **M3 Definida:** responsabilidades, proceso y evidencia establecidos.
- **M4 Gestionada:** capacidad controlada, medible y revisada.
- **M5 Optimizada:** mejora continua, aprendizaje y adaptación.

## Separaciones obligatorias

- Puntaje de assessment ≠ riesgo.
- Riesgo ≠ prioridad.
- Nivel global del assessment L1–L5 ≠ madurez de capacidad M0–M5.
- Madurez M0–M5 ≠ complejidad T1/T2/T3.
- Complejidad ≠ profundidad de servicio.

No se desarrollarán todavía las 120 definiciones CAP × M. Se enriquecerán con evidencia de ejecución y aprendizaje real.

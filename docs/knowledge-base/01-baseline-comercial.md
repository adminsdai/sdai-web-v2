## Posicionamiento

SDAI PYME no se plantea como certificación ni como cumplimiento primero. El principio comercial es:

> No vender cumplimiento. Vender preparación.

Promesa: **Conoce dónde estás. Prioriza lo importante. Empieza a prepararte.**

Ciclo: `RADAR → ASSESSMENT → PRIORIDAD → ACCIÓN → EVIDENCIA → EVOLUCIÓN`.

## Flujo comercial objetivo

`RRSS / Google / referidos → /pyme/ → Diagnóstico SDAI PYME → Sesión ejecutiva → Resultado de preparación → Plan 90 días → Acompañamiento mensual → Proyectos especializados`

## Reglas

- El resultado en pantalla permanece disponible sin exigir datos comerciales.
- El PDF identificado es un activo de valor agregado.
- Captura de datos necesaria para el servicio y consentimiento de marketing deben permanecer separados.
- El lead todavía no se persiste automáticamente en CRM en esta baseline.
- La propuesta económica no se envía automáticamente: requiere revisión de un consultor SDAI.

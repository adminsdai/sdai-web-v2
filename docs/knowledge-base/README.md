## Propósito

Esta carpeta conserva la memoria de diseño, decisiones, supuestos, modelos y evolución de SDAI PYME. Su objetivo es permitir revisar por qué se adoptó una decisión, evaluar su desempeño y reformularla de manera controlada a medida que aumente la madurez del producto.

## Regla de autoridad

Esta Knowledge Base **no reemplaza el canon institucional SDAI**. FOUNDATION-001 v2.0, CATALOG-001 v2.0 y los activos canónicos vigentes mantienen precedencia. Cuando una decisión de esta carpeta deba incorporarse al canon, debe pasar por Governance Review y control de cambios.

## Principios

1. Separar hechos, decisiones, hipótesis y temas pendientes.
2. No sobrescribir silenciosamente una decisión histórica.
3. Toda reformulación relevante debe indicar versión, motivo e impacto.
4. Mantener trazabilidad entre Assessment, CAP, madurez, SRV, ACT, PRF, HH, complejidad, tarifa y cotización.
5. Puntaje, riesgo, prioridad, madurez y complejidad son conceptos distintos.
6. La aplicabilidad regulatoria se determina; no se presume.
7. Una recomendación automática nunca sustituye la revisión profesional SDAI.

## Estados documentales

- **WORKING:** análisis en desarrollo.
- **BASELINE:** suficientemente estable para uso operacional.
- **REVIEW:** sometido a revisión.
- **SUPERSEDED:** reemplazado, conservado por trazabilidad.

## Evolución

Una nueva versión debe registrar: fecha, cambio, fundamento, artefactos afectados y compatibilidad con versiones anteriores. Las versiones históricas no deben eliminarse cuando sean necesarias para explicar propuestas, diagnósticos o decisiones ya emitidas.
